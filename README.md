# ShuttleSync - Smart Campus Mobility Platform

ShuttleSync ("Know Before You Go") is a campus transit application designed to solve student commute challenges identified in Project P05 (Waiting for the Shuttle).

## Features
- Interactive Campus Map with real-time moving shuttles and animated shuttle cursor
- Predictive ETA forecasting with dynamic traffic, speed, and weather controls
- Crowd monitoring with occupancy percentage and capacity levels
- Smart stop recommendation engine based on distance and wait times
- Journey planner with multi-modal walking and shuttle connections
- Notification alert center for delays, crowded shuttles, and arrivals
- Driver console with one-touch stop arrival and passenger counter
- Admin simulation dashboard for fleet oversight and traffic parameters
- Design Thinking methodology dossier covering Empathy, Observation, Define, Ideation, Prototype, and Testing stages

## Quick Start
```bash
npm install --legacy-peer-deps
npm run dev
```

Build for production:
```bash
npm run build
```
